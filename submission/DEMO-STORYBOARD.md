# Patchline — recorded demo

**Final cut:** 86.64 seconds, 1280 × 720, silent H.264 MP4. The [MP4](Patchline-Demo.mp4) was captured from the actual browser app with a visible cursor and captions. Every reading is synthetic. No physical patch or treatment is shown.

| Approximate time | What the viewer sees |
|---|---|
| 0–8 s | Concept bandage and simulation label; enter the prototype. |
| 8–18 s | Stable four-channel trace; quality passes and virtual outputs stay at zero. |
| 18–31 s | Change a final synthetic reading and reset it. |
| 31–43 s | Pattern change prompts a human-review handoff; abstract output tokens are labeled as non-doses. |
| 43–57 s | Sensor fault: pH outlier plus missing glucose; score withheld and both virtual outputs at zero. |
| 57–70 s | Handoff claims link to both flagged source samples, with model provenance and event log. |
| 70–76 s | One-page print layout. |
| 76–87 s | Explicit limits and “Built by Rishik Rontala.” |

The same browser flow is scripted in `record-demo.cjs`. The video has no audio track and was not played through speakers during testing.
